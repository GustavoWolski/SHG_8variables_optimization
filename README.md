# Optical Parameter Identification

Projeto para identificação inversa de parâmetros ópticos usando ajuste simultâneo de transmissão e reflexão.

## Documentação

- `docs/metodologia.md`: metodologia experimental e comparação dos algoritmos.
- `docs/equacoes.md`: equações e interpretação física.
- `legacy_matlab/`: implementação MATLAB original.
- `AGENTS.md`: instruções obrigatórias para agentes de código.

## Objetivo inicial

Reproduzir em Python o simulador MATLAB e validar equivalência numérica.

Depois comparar:

- Random Search
- Differential Evolution
- Genetic Algorithm
- PSO
- CMA-ES
